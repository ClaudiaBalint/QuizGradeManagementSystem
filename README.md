# Quiz Grade Management System

A web application for managing classes, quizzes, students, teachers, and test results.

## Technologies

- PHP
- JavaScript
- CSS
- MySQL
- Composer

## Features

- User registration and login
- Student and teacher roles
- Class management
- Quiz creation
- Quiz viewing and participation
- Test result management
- Student and teacher dashboards
- Email validation

## Project Structure

- `*.php` - application pages and backend logic
- `js/` - JavaScript functionality
- `css/` - application styling
- `images/` - application images and icons
- `config.php` - application/database configuration
- `composer.json` - PHP dependencies
